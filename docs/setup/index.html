Put your Ticker on WiFi from a computer

Use this if the phone method did not work. It needs Chrome or Edge on a Mac, Windows or Chromebook. Safari and iPhone cannot do it.

  1. Plug the Ticker into this computer with a USB-C data cable.
  2. Click the button below and pick the port called USB JTAG/serial debug unit.
  3. Enter your WiFi name and password.
  4. Watch the Ticker: it says WIFI OK and restarts. Done.

This browser cannot talk to USB devices. Use Chrome or Edge. Open this page over https, or save it and open the file.

If the Ticker says WRONG PASSWORD or WIFI NOT FOUND, try again. The Ticker joins 2.4 GHz networks only.
